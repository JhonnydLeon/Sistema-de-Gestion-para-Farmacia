# Sistema de Gestión para Farmacia

Proyecto académico de Sistemas de Información II (UPDS, Sede Santa Cruz).
Sistema de ventas y administración de farmacia hecho con PHP y MySQL.


## Cómo ejecutar
1. Instalar XAMPP e iniciar Apache y MySQL.
2. Copiar el proyecto en C:\xampp\htdocs\
3. Abrir http://localhost/phpmyadmin y crear una base de datos llamada: [v_farmacia]
4. Importar el archivo v_farmacia.sql en esa base de datos.
5. Verificar en conexion.php que el puerto y el nombre de la base coincidan (puerto: [3306]).
6. Abrir http://localhost/Sistema_Farmacia/ en el navegador.
